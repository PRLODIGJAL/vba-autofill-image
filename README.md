# 项目4 · VBA 自动铺满图片

Excel VBA 宏工具，自动在操作指导书的图片格位里铺满图片。省去手动一张张拖拽调整的时间。

## 文件

| 文件 | 说明 |
|---|---|
| `3代b硅油涂层操作_图片格位版.xlsm` | 成品（含 VBA 宏），3 代 b 版为最新定稿 |
| `使用说明书.txt` | 使用文档 |

## 怎么用

1. 用 Microsoft Excel 打开 `.xlsm` 文件（需要启用宏）
2. 按说明书操作即可

## 说明

- 文件包含 **VBA 宏代码**，Excel 打开时选择「启用宏」
- 此为最终成品（3 代 b 版），原始模板和历代迭代版本不在此仓库中
